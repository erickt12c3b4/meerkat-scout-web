Channels · Walmart

The one channel where you paste credentials instead of clicking Authorize — because that's how Walmart hands them out.

Walmart Marketplace issues each seller their own API keys in Seller Center. There is no OAuth screen to send you to. Scout gives you two fields, encrypts what you paste, and reads your item spec and GTIN exemption status from Walmart directly.

How Scout connects

3 steps, in the app.

Scout holds only the credential the channel issues for this connection, encrypted at rest. Disconnecting the channel deletes it.

  1. 01Generate API keys in Seller CenterUnder Developer Portal → API Keys, create a Client ID and Client Secret for Scout.
  2. 02Paste them into ScoutTwo fields. Scout encrypts both at rest with keys held in a key management service; nobody at Scout can read them back.
  3. 03Scout verifies the connectionA read-only call confirms the keys work and pulls your item spec version and GTIN exemption status.

What makes Walmart different

Two fields, encrypted on arrival. Then Walmart tells Scout what your account is allowed to do.

What Scout does for Walmart

01

Resolves each product to a Walmart item spec category with confidence and reason, and validates its required attributes before submission.

02

Reads GTIN exemption status from Walmart rather than assuming — so items are validated against the rule that actually applies to you.

03

Translates feed status and item errors into Scout's vocabulary with the attribute named.

What Walmart requires that others don't

  • Per-seller API credentials pasted in, not authorized through a login.
  • A Walmart item spec category per product, with that category's required attributes.
  • A GTIN per item unless Walmart has granted you an exemption for that category.

Scout's starter template for Walmart pre-maps these from Shopify where a mapping exists, and its diagnostics name the field when one is missing.
